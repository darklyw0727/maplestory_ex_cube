# 自動洗閃炫方塊
此專案使用python讀取當前電腦畫面並控制滑鼠以達到自動使用楓之谷"珍貴附加方塊"、"絕對附加方塊"、"萌獸方塊"或"恢復附加方塊"的功能

# 程式執行設定
使用者在程式執行前可以設定以下內容:
- 使用閃炫方塊後所需要的目標潛能組列表
	- 一組目標潛能最多可以選擇0-3個
	- 一組目標潛能在設定檔中以一個字串陣列的形式存在
	- 允許空字串，代表除其他目標潛能外的所有潛能
	- 目標潛能組沒有數量限制
	- 第一個目標潛能組擁有最高的優先級，依次往下
	- 潛能組中的潛能沒有順序之分 (例如設定中的第2個潛能可以匹配遊戲畫面中的第1個潛能)
- 使用者可以設定最多使用多少方塊
	- 設定值為0時代表不限制

# 洗方塊流程
程式會根據讀取到的方塊名稱而有不同的運作流程，主要分為以下兩種

## 流程規劃 ("珍貴附加方塊"、"絕對附加方塊"或"萌獸方塊")
"萌獸方塊"的操作流程與"珍貴附加方塊"、"絕對附加方塊"完全一致。
1. 使用者須提前開啟使用方塊的介面並點選"珍貴附加方塊"、"絕對附加方塊"或"萌獸方塊"
(以下皆為程式自動控制)
2. 判斷當前畫面中使用者選擇的是否是"珍貴附加方塊"、"絕對附加方塊"或"萌獸方塊" (如圖step1紅框)
3. 控制滑鼠按下"重新設定"按鈕 (如圖step2紅框)
4. 遊戲畫面中出現提示框，程式操控滑鼠按下"確定"按鈕 (如圖step3紅框)
5. 遊戲畫面出現3個潛能選項(如圖step4紅框)，程式讀取3個選項的內容並根據使用者設定的內容進行判斷，若3個選項的內容符合潛能組擲中的設定則關閉程式，反之則重複步驟2到5直到達成目標
	- 目標潛能組中的空字串代表任意"非目標潛能"的潛能

## 流程規劃 (恢復附加方塊)
1. 使用者須提前開啟使用方塊的介面並點選"恢復附加方塊"
(以下皆為程式自動控制)
2. 判斷當前畫面中使用者選擇的是否是"珍貴附加方塊"或"絕對附加方塊" (如圖stepa1紅框)
3. 控制滑鼠按下"重新設定"按鈕 (如圖stepa2紅框)
4. 遊戲畫面中出現提示框，程式操控滑鼠按下"確認"按鈕 (如圖stepa3紅框)
5. 遊戲畫面出現2個潛能組(一組有3個潛能)，程式讀取右邊潛能組3個選項的內容(如stepa4紅框)並根據使用者設定的內容進行判斷:
	- 若3個選項的內容符合潛能組列表中任意一個潛能組的設定則點選右邊的潛能組並關閉程式
	- 若3個選項的內容沒有符合潛能組列表中任意一個潛能組的設定則點選"重新設定1次" (如stepa5紅框)
		- 按下重新設定後會有一個提示框要求使用者按下確認(如stepa6紅框)並重複步驟4到5
	- 目標潛能組中的空字串代表任意"非目標潛能"的潛能
